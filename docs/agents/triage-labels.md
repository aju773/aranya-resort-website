# Triage labels

Use these exact strings for local ticket triage status.

| Role | Local label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs evaluation |
| needs-info | needs-info | Waiting for information |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

Approved implementation tickets start with `Status: ready-for-agent`. Blockers still govern when work may begin.
